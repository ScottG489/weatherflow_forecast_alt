# WeatherFlow Forecast (alternate fork)

Use a public Tempest station ID with automatic anonymous-session renewal, or
choose Personal access token for a station you own. Includes daily/hourly
forecasts and optional station sensors.

Existing map-key entries migrate automatically while preserving entity IDs and
settings. Minimum Home Assistant: 2025.3.4.

Install from ScottG489/weatherflow_forecast_alt. See the repository README for
setup, migration and access-policy details.
